## 専用プロフィールの作り方

これはサポートサイト内の検証用プロフィール。エステレラ公式への新規会員申込み・購入は不要。

1. 所有者として既存の管理画面 `/affiliate-settings` を開く。既存の所有者サインイン、または所有者が既に保有する正規管理URLを使う。新しい鍵の発行、鍵の抽出、認証回避は行わない。
2. 一覧の検索欄で利用予定IDを検索し、**未使用であることを所有者が確認する**。検索欄の表示は「紹介者名で検索」だが現行コードはID検索にも対応する。登録APIは同じIDを更新する方式なので、既存会員のIDを入力してはならない。未使用IDをこちらで推測して採番しない。
3. 「紹介者情報を登録する」で以下を入力する。

| 項目 | 入力 |
| --- | --- |
| アフィリエイトID | 未使用と確認した、2桁以上の数字のみの専用ID |
| 紹介者名 | `ESTLELA検証専用`（完全一致・余分な空白なし） |
| クーポンコード | `TESTONLY`（フォームの必須欄を満たすテスト値。実クーポンとして案内しない） |
| クーポン有効期限 | 空欄 |
| LINEまたは問い合わせURL | 空欄 |
| この紹介者IDを有効にする | オン |

4. 保存後、`ESTLELA検証専用` の活動実績を開き、「本人専用URLをコピー」を使う。
5. コピー元は `/affiliate-activity?ref=…&token=…`。共有用の `/?ref=…`、「紹介サイトURLをコピー」、Cookie使用後の `?session=mt` は検証用Secretに使えない。
6. 専用プロフィールを実際の紹介、購入、動画配信や通知登録には使わない。URLはGitHub Secretへ直接保存し、チャット・Issue・ソース・ログへ貼らない。

通常の正規認証は署名付き個別URL → `/api/mt-session` → HttpOnly / Secure / SameSite=Strict Cookie。IDのみでは認証されない。検証APIは「専用ID設定」「有効なプロフィール」「名前の完全一致」「正しい署名トークン」「ビルド指紋」を確認するだけで、認証情報を新規発行しない。
